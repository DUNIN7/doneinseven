# doneinseven.com

DUNIN7 company / product-family root page. Static HTML served via Cloudflare Pages.

## Stack

Plain HTML with inline CSS. No build tooling, no framework, no JavaScript.

## Deployment

Cloudflare Pages auto-deploys on push to `main`. Production domain: `doneinseven.com`.

## Editing

Edit `index.html` directly. Commit and push to `main` — Cloudflare Pages picks up the change and re-deploys within ~1 minute.
